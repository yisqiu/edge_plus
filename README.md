Edge浏览器右键关闭标签页插件

# 功能
- 采用转发中键关闭标签方式，效率更高，保留基本功能，去除冗余功能
- 采用右键弹起时触发消息事件，增加兼容性
- 小键盘回车采用第二搜索引擎（在地址栏中输入关键词，如果直接按小键盘上面的回车键，将采用第二搜索引擎进行搜索，该搜索引擎可以在配置文件中自定义）
- 地址栏全角字符自动转换功能：：转换成:   、转换成/
- 右键标题栏空白区域打开新标签
- 地址栏回车新开tab打开网页（支持自定义搜索引擎）
- 右键关闭标签页
- 按住右键时滚轮滚动标签栏（暂时取消）
- 支持Edge（140版本）
# 获取
下载KBDUS1.3.0.exe
# 安装
- 双击KBDUS1.3.0.exe运行
